# Мастерская Изобретателя

Обучающая игра-конструктор для детей: собери схему по шагам — и она оживёт.
Сейчас готов мир «Электрика» (MVP): 8 уровней по инструкции, 6 задачек и Мастерская-песочница.

```bash
npm install
npm run dev     # разработка
npm test        # тесты симуляции и уровней
npm run build   # статический сайт в dist/
```

- `?all=1` в адресе — открыть все уровни и Мастерскую (для взрослых).
- Управление: перетащи деталь из палитры; провод — протяни мышкой; R / колесо — повернуть;
  правая кнопка / Delete — убрать; Ctrl+Z — отменить; щелчок по выключателю/кнопке — нажать.

Структура: `src/core` (сетка, реестр деталей, соединения), `src/sim` (MNA-электрика, цели),
`src/render` (canvas, спрайты), `src/audio` (Web Audio), `src/ui` (экраны, тексты в `texts.ts`),
`src/levels/*.json` (уровни), `src/save` (localStorage), `tests/`.
